# SLA-Timer-sd.bitech.com.ua
Таймер SLA для sd.bitech. Дані SLA бере напряму з сайту, тож оновлювати таймери вручну не потрібно.
Деталі та обговорення в гілці discord. Ну або тут 😺.

На зараз:
- відображається на сторінці заявок коло статусу для всіх заявок, в самій заявці на всіх блоках;
- таймер у заявці розташований над кнопками лівого меню, без вертикальних відступів;
- бере таймер SLA з API сайту — те саме значення, що й стандартна колонка «Таймер задачі»: враховує критичність, усі призупинення, їх дострокове зняття та зв'язані заявки;
- показує фактичний час до дедлайну, зокрема для призупинених заявок; у підказці видно дедлайн і час останнього оновлення даних;
- клік на таймер у заявці копіює дату й час завершення SLA;
- клік лівою або правою кнопкою на таймер у списку відкриває меню копіювання SLA та редагування розташування;
- редактор дозволяє змінити горизонтальне й вертикальне зміщення, ширину, висоту та розмір тексту всіх таймерів списку; зміни видно одразу, вони зберігаються у браузері та не збільшують висоту рядків; кнопка «Скинути» відновлює стандартні значення;
- є індикація кольором, зеленим виділяється актуальний час, червоним — прострочений, а також проміжок у дві години до завершення; 
- час показує динамічно, дані з сайту оновлює раз на хвилину.

Скрипт лише читає дані: бере їх із відповідей сайту, а раз на хвилину (і коли даних ще немає) сам запитує SLA видимих заявок. Токен доступу сайту не зберігається і нікуди не передається.
